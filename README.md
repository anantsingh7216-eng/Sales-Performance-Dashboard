# 📊 Sales Performance Dashboard

An interactive **Sales Performance Dashboard** built using HTML, CSS, JavaScript, and Chart.js to analyze sales, profit, product performance, country-wise sales, and discount impact.

The dashboard provides interactive visualizations and filtering capabilities to explore business performance from September 2013 to December 2014.

## 🚀 Project Overview

The Sales Performance Dashboard transforms financial sample data into an interactive business intelligence report. Users can explore key performance indicators (KPIs), compare monthly sales and profits, and analyze product and segment performance.

This project demonstrates practical skills in data visualization, dashboard design, and business data analysis.

## ✨ Features

* 📈 **Monthly Sales vs Profit:** Compare sales and profit over time.
* 📦 **Sales by Product:** Analyze sales across different products.
* 🏢 **Profit by Segment:** Compare profitability across customer segments.
* 🌍 **Sales by Country:** Explore country-wise sales performance.
* 💰 **Profit Margin by Discount Band:** Analyze profit margins across discount categories.
* 🎯 **Interactive Filters:** Filter dashboard data to explore specific categories.
* 🔄 **Cross-Filtering:** Click chart bars or slices to filter related visualizations.
* 📊 **KPI Cards:** Display key business performance indicators.
* 🌙 **Dark Mode Support:** Supports dark and light appearance settings.
* 📱 **Responsive Design:** Dashboard layout adapts to different screen sizes.
* ♻️ **Reset Filters:** Restore the dashboard to its default view.

## ▶️ How to Run the Project

### Option 1: Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The dashboard will open in your web browser.
5. Use the available filters and charts to explore the data.

### Option 2: Run with VS Code

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Run the file in your browser.
4. For a convenient development workflow, use the Live Server extension.

**Requirement:** An internet connection is needed to load the Chart.js library from its CDN.

## 📊 Dataset Information

The dashboard uses a cleaned Financial Sample dataset.

* **Reporting Period:** September 2013 – December 2014
* **Transactions:** 700
* **Segments:** Channel Partners, Enterprise, Government, Midmarket, Small Business
* **Products:** Amarilla, Carretera, Montana, Paseo, VTT, Velo
* **Countries:** Canada, France, Germany, Mexico, United States of America
* **Discount Bands:** High, Low, Medium, None

Blank discount band values are categorized as `None` in the dashboard data.
